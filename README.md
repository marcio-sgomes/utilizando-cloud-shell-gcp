# Desafio de Projeto - Utilizando o Cloud Shell no Google Cloud

Repositório criado para a entrega do projeto prático da DIO, focado na utilização do Google Cloud Shell para gestão de recursos e execução de comandos diretamente via navegador.

## 🛠️ O que foi realizado:
- **Acesso ao Cloud Shell:** Inicialização do terminal integrado na web do GCP sem necessidade de instalações locais.
- **Execução de Comandos:** Utilização de ferramentas de linha de comando para interagir com o ambiente e projetos na nuvem.

## 🚀 Tecnologias:
- Google Cloud Shell (GCP)
- Git e GitHub
